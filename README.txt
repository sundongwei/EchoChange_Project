EchoChange Academic Research Showcase
=====================================

1. Extract the complete ZIP archive before opening the presentation.
2. Double-click "Open EchoChange.bat" or open "Open EchoChange.html" directly.
3. Navigate with the section header, bottom controls, arrow keys, mouse wheel, or touch gestures.
4. The presentation runs fully offline and requires no Node.js, Python, or development environment.
5. The site folder contains the videos, T1/T2 inputs, inference traces, and reports. Keep it beside the HTML file.

For the best presentation experience, use a recent version of Chrome or Edge and maximize the browser window.
